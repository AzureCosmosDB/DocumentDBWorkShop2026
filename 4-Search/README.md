# Module 4: Search in Azure DocumentDB

Start with a `before` notebook in Python, C#, or Node.js. The `before` notebooks contain guided `STUDENT EXERCISE` cells with focused TODOs. The matching `after` notebooks contain completed reference solutions.

Participants paste a DocumentDB connection string and OpenAI API key, generate embeddings, create DocumentDB vector and full-text indexes, and compare vector, BM25, fuzzy, phrase, and hybrid search.
